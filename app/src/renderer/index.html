LiveProject muestra tu proyecto web en varios dispositivos a la vez (móvil, tableta, portátil, monitor), lo recarga al guardar y reúne en un solo lugar los errores, las peticiones de red, los enlaces rotos y los problemas de CSS responsive. Funciona con cualquier backend: PHP, Laravel, Django, Flask, Node, Ruby, Go o sitios estáticos.


          
🚀 Primeros pasos
            
    
              
  1. Pulsa 📂 Abrir y elige la carpeta de tu proyecto (o ejecuta liveproject . en la terminal).
    2. 
              
  2. LiveProject detecta el servidor (php -S, artisan serve, manage.py runserver, Flask, npm run dev, Rack, Go…) y lo arranca. El indicador junto al nombre pasa de iniciando… a activo.
    3. 
              
  3. Tu página aparece dentro de los dispositivos. Edita y guarda un archivo: todas las vistas se recargan solas.
    4. 
              
  4. Si el proyecto ya tiene servidor (XAMPP, Docker…), indica su dirección con "url" en .liveproject.json y no se lanzará ningún proceso.
    5. 
            

          


          
🧭 Recorrido por la interfaz
            
    
              
  • Barra superior: abrir proyecto, estado del servidor, dirección, ⟳ Recargar y ⏻ Reiniciar el servidor, y los menús 👁 Vista y 🧰 Herramientas.
    • 
              
  • Barra de dispositivos: botones para activar o desactivar cada pantalla. Se pliega con el título Dispositivos.
    • 
              
  • Escenario: el centro, donde viven los dispositivos. Si no caben, desplázate horizontalmente.
    • 
              
  • Barra de rendimiento (bajo el escenario): puntuación y métricas de carga por dispositivo. Plegable.
    • 
              
  • 🗂 Paneles (derecha): Mensajes, Red, Enlaces, Rutas e Historial. Arrastra el separador para cambiar el ancho.
    • 
              
  • 🔍 Inspector (abajo): Inspector inteligente, DevTools, CSS responsive y registro del servidor. Arrastra el separador para cambiar la altura.
    • 
              
  • ⚙ Ajustes: dispositivos, IA, tema, aplicación y este manual.
    • 
            

            
Cada panel se abre y se cierra desde su botón; la app recuerda el ancho del panel lateral y qué secciones plegaste.

          


          
📱 Dispositivos y rotación (vertical / horizontal)
            
    
              
  • Activa o desactiva dispositivos en la barra de dispositivos. En Ajustes → Dispositivos puedes añadir, renombrar, cambiar medidas o elegir entre los presets 2025-2026 (iPhone 17, Galaxy S26, Pixel 10, iPad Pro, MacBook, monitores 2K/4K…).
    • 
              
  • Cada teléfono y tableta tiene un botón ⟲ Girar en su título: pulsa para verlo en horizontal y vuelve a pulsar para regresar a vertical. El ancho y el alto se intercambian, así que las media queries y orientation reaccionan como en un aparato real.
    • 
              
  • Para girarlos todos a la vez: 👁 Vista → ⟲ Girar móviles y tabletas.
    • 
              
  • La orientación se conserva al recargar y al cambiar otras opciones de dispositivos.
    • 
              
  • Ajustar a la pantalla: reduce cada dispositivo para que quepa en la altura disponible (muestra el % de escala). Si lo desactivas, ves el tamaño real con desplazamiento.
    • 
              
  • Sincronizar: el scroll, los clics y lo que escribes o eliges en formularios (texto, listas, Enter para enviar) se repiten en las demás vistas.
    • 
            

          


          
⚙️ Servidor y archivo .liveproject.json
            
Crea este archivo en la raíz del proyecto para personalizar el comportamiento:

            
{
  "command": "python3 -m http.server {port}",
  "port": 8000,
  "url": "http://localhost:8080",
  "path": "/",
  "ignore": ["logs"],
  "delay": 0
}

            
    
              
  • command: comando que arranca el servidor. Admite {port} y {root}.
    • 
              
  • url: usa un servidor que ya está en marcha, sin lanzar nada.
    • 
              
  • path: ruta que se abre al inicio. ignore: carpetas que no provocan recarga. delay: espera (ms) antes de recargar.
    • 
            

            
Capturas, sesiones e informes se guardan en <proyecto>/.liveproject/; añádelo a tu .gitignore. La pestaña Servidor del panel inferior muestra la salida del proceso.

          


          
✨ Inspector inteligente
            
    
              
  • Árbol del DOM con barras de tamaño: las rojas indican elementos que desbordan el ancho de la pantalla.
    • 
              
  • Selecciona un nodo para ver su modelo de caja, estilos calculados y fragmento HTML.
    • 
              
  • 🎯 Elegir en la página: haz clic en la vista y se selecciona el elemento. Al pasar el ratón por el árbol, se resalta en la página.
    • 
              
  • A la derecha, un resumen: problemas de accesibilidad, responsive y contraste, paleta de colores y esquema de encabezados.
    • 
              
  • Con Analizar al recargar se actualiza solo. Elige el dispositivo a inspeccionar en el selector Dispositivo.
    • 
            

          


          
🛠 DevTools y 📐 CSS responsive
            
    
              
  • DevTools: las herramientas reales de Chromium (Elements, Console, Sources, Network…) acopladas al dispositivo elegido.
    • 
              
  • CSS responsive: pulsa ▶ Analizar dispositivos activos y se revisa cada pantalla con su tamaño real: desbordes, anchos fijos, objetivos táctiles pequeños, tipografía, imágenes, 100vh, media queries… Cada hallazgo propone una corrección y, al pulsarlo, resalta el elemento en la página.
    • 
              
  • Con IA conectada aparecen Corregir con IA y 💡 Revisión con IA, que prioriza los problemas y propone el CSS corregido.
    • 
            

          


          
💬 Panel de Mensajes
            
    
              
  • Reúne errores y avisos de PHP, Python, Node, Ruby, Go, Java, C#, SQL, HTTP y JavaScript, tanto de la salida del servidor como los impresos en la propia página.
    • 
              
  • Cada mensaje lleva etiqueta de lenguaje y color por gravedad (rojo error, ámbar aviso, azul nota). Los repetidos se agrupan con un contador.
    • 
              
  • Filtra por gravedad o por lenguaje (clic en la etiqueta). Pulsa el título para ver el detalle completo.
    • 
              
  • Con IA conectada, 💡 Explicar con IA te dice la causa y la solución. La casilla Explicar errores automáticamente lo hace sola con IA local (máx. 20 por sesión).
    • 
            

          


          
🌐 Panel de Red
            
    
              
  • Todas las peticiones de cada vista: método, estado, tipo, tamaño, tiempo y cabeceras clave. Pulsa una fila para ver el detalle.
    • 
              
  • Filtra por tipo o texto de URL, o activa Solo fallos. Los 4xx/5xx y los fallos de red se añaden también a Mensajes.
    • 
              
  • Conservar al recargar mantiene el historial entre recargas.
    • 
            

          


          
🔗 Panel de Enlaces
            
Pulsa 🔗 Comprobar para validar enlaces, imágenes, scripts, estilos, iframes y medios (HEAD/GET). Detecta además anclajes #id inexistentes, contenido mixto http/https y redirecciones. Cambia el filtro entre Problemas y Correctos.

          


          
🧭 Panel de Rutas
            
    
              
  • Lista las rutas del proyecto para llegar a cualquier página (/login, /admin…) sin escribir la dirección a mano. Se apoya en tres fuentes: el código (definiciones de Laravel, Symfony, Django, Flask/FastAPI, Express, NestJS, Rails, Gin/Echo, Spring, ASP.NET, Next, Nuxt, React/Vue Router, SvelteKit, Astro y páginas PHP/HTML), los enlaces de las páginas cargadas y las rutas que ya has visitado.
    • 
              
  • 🧭 Explorar vuelve a recorrer el proyecto; la casilla Enlaces de la página añade también los enlaces de cada vista al cargarlas.
    • 
              
  • Clic en una ruta: todas las vistas navegan a ella (también en modo completo). Shift+clic: solo la vista elegida en el inspector.
    • 
              
  • ✔ comprueba cada ruta con HTTP y muestra su código: verde (2xx), ámbar (redirección), rojo (4xx/5xx o sin conexión). Las rutas con parámetros (/users/:id) se marcan como parámetro y no se comprueban.
    • 
              
  • Cada fila indica el origen: fichero y línea cuando procede, o si vino de la página o de una visita. Filtra por ruta, fichero o etiqueta con el cuadro de texto.
    • 
            

          


          
🕘 Historial e 📄 informes
            
    
              
  • Cada sesión se guarda sola en .liveproject/sessions/ (las últimas 50). Puedes reabrirlas o borrarlas desde Historial.
    • 
              
  • 🧰 Herramientas → 📄 Exportar informe genera un HTML y un Markdown en .liveproject/reports/ con errores, red, enlaces, CSS responsive y rendimiento.
    • 
              
  • 📷 Captura guarda una imagen de cada vista en .liveproject/screenshots/.
    • 
            

          


          
⚡ Barra de rendimiento
            
Mide TTFB, FCP, LCP, CLS, TBT, tiempo de carga, peso, peticiones, nodos del DOM y memoria con los umbrales de Google (Lighthouse). Muestra una nota global por dispositivo; pulsa un dispositivo para inspeccionarlo. Pliégala con el título Rendimiento si necesitas más espacio.

          


          
📡 Red local (móvil real, tableta y otros equipos)
            
    
              
  1. Pulsa 📡 Red local y activa el acceso. Se crea un proxy (puerto 4777 o uno libre).
    2. 
              
  2. Escanea el código QR con el móvil o escribe la URL en otro equipo de la misma red.
    3. 
              
  3. Los dispositivos se recargan al guardar, funcionan con HMR/WebSocket y sus errores de JavaScript llegan al panel Mensajes.
    4. 
            

            
Mientras está activo, cualquier equipo de la red puede ver tu proyecto. Si no conecta, abre el puerto en el cortafuegos. Desactívalo cuando termines.

          


          
🤖 Inteligencia artificial
            
    
              
  • Local (Ollama, LM Studio): gratis y privado; nada sale de tu equipo.
    • 
              
  • API (Anthropic, OpenAI, Gemini): de pago por uso; pega tu clave de API.
    • 
              
  • Suscripción: usa la CLI oficial de Claude Code, Codex o Gemini CLI.
    • 
              
  • En Ajustes → Inteligencia artificial elige proveedor, pulsa 🔌 Conectar y selecciona un modelo de la lista. El punto de color indica el estado: verde conectado, rojo error, ámbar comprobando, gris sin conectar.
    • 
              
  • Las sugerencias se ajustan a la RAM de tu equipo. En local, el servidor (p. ej. ollama serve) debe estar en marcha.
    • 
            

          


          
🎨 Tema y apariencia
            
En Ajustes → Tema elige modo Oscuro, Claro o Sistema, un color de acento (paleta o selector libre) y el tamaño de la interfaz (80 %–140 %). Solo afecta a LiveProject, no a tus páginas.

          


          
🛠 Actualizaciones y desinstalación
            
    
              
  • Ajustes → Aplicación: indica la URL de actualizaciones (JSON con version y url, o la API de GitHub Releases) y pulsa Buscar actualizaciones. Puedes activar la búsqueda al iniciar.
    • 
              
  • Desinstalar elimina el AppImage o el paquete .deb (pide contraseña). Marca la casilla si quieres borrar también tus ajustes y claves.
    • 
            

          


          
🩺 Solución de problemas
            
    
              
  • Estado «sin respuesta»: el servidor no arrancó. Revisa la pestaña Servidor, el comando de .liveproject.json y que el puerto esté libre. Prueba ⏻ Reiniciar.
    • 
              
  • No recarga al guardar: comprueba que la carpeta no esté en ignore y que el servidor no use caché agresiva.
    • 
              
  • El móvil real no conecta: debe estar en la misma red; abre el puerto 4777 en el cortafuegos.
    • 
              
  • La IA no responde: pulsa Comprobar conexión; en local verifica que Ollama/LM Studio estén en ejecución y el modelo instalado.
    • 
              
  • Los dispositivos no caben: activa Ajustar a la pantalla, cierra paneles o baja el tamaño de la interfaz en Tema.
    • 
              
  • Texto muy pequeño o grande: Ajustes → Tema → Tamaño de la interfaz.
    •
